# MiGuOrca

MiGuOrca is an anime RSS subscription orchestration tool.

The MVP focuses on a single-bangumi flow:

1. Receive one bangumi title.
2. Search and analyze MiKanProject data.
3. Generate a confirmable Request.
4. Submit to Auto Bangumi or export a JSON fallback config.

See `docs/MiGuOrca_main_PRD.md` for the current product requirements.
