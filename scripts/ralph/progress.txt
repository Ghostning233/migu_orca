## 2026-09-18 - WP-42-A / US-346 开发与定向验证

- 范围与落点：只改 `frontend/src/app/stores/notification.ts`、
  `frontend/src/components/feedback/GlobalNotification.vue`、受影响 Vitest（`App.test.ts`、

  client/后端、草案与保存确认契约、追番管理/设置业务、外部写或任何业务成功判定。
- 实现：
  - 单一 store 新增 `NOTIFICATION_AUTO_CLOSE_MS`（success/info 10s、error 20s）；`show()` 先按
    上一条消息 id 取消其 timer，再为新 id 建 timer；timer 回调只清理自己 id 的消息（`current?.id`
    守卫）。未定义 kind 不落任何时长，改为手动关闭，避免静默取得不安全默认。
  - `clear()` 取消当前消息 timer；timer 存在模块级 Map（不进 Pinia 响应式 state），
    到期/替换/clear/卸载四条路径各自移除，任意时刻至多一条挂起。
  - `GlobalNotification` 改为 `position: fixed`（header 下方右上、`--z-overlay`），容器
    `pointer-events: none` 让点击穿透、关闭按钮 opt-in `auto`；`role`/`aria-live` 改为白名单：
    success/info 才 polite+status，其余（含未定义 kind）fail closed 为 assertive+alert，
    保留 `aria-atomic="true"`；`onBeforeUnmount` 清理 store，避免 orphan timer。
  - 未新增 loading kind：核对全部 46 处既有 `notification.*` 调用点均无短时全局进行中需求，
    页面 loading/disabled 仍由各页面就地持有，故不引入第二套通道。
