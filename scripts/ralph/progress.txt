## Codebase Patterns
- Active Stage 11 PRD lives in `scripts/ralph/prd.json`.
- Stage 11 scope is BL-004: Web UI explicit real MiKan / Auto Bangumi configuration entry.
- Default CLI and Web UI generation must remain offline and fixture-backed unless the user explicitly opts into real integrations.
- Default generation must not write local storage unless the caller explicitly opts into persistence through `--save-request` or Web API `save_request=true`.
- Real MiKan configuration in Stage 11 is request-scoped: do not write `search_endpoint` or related config into storage JSON, status history, browser localStorage, or URLs.
- Auto Bangumi configuration in Stage 11 is request-scoped: never persist token, endpoint, Authorization header, cookies, or complete URLs into storage JSON, localStorage, sessionStorage, logs, API responses, screenshots, traces, or docs examples.
- Web API must continue returning the unified envelope: success `{ok: true, result: ...}` and failure `{ok: false, error_type, error_message}` through `extensions.flask_api`.
- API and UI errors must remain sanitized: do not expose raw HTML, raw RSS XML, complete endpoint URLs, cookies, tokens, Authorization headers, local absolute paths, or sensitive fallback fields.
- Keep the Web UI Flask server-rendered with minimal JavaScript; do not introduce React/Vite or a frontend build chain.
- Web UI assets live under `src/apps/migu_orca_web/templates/migu_orca_web/` and `src/apps/migu_orca_web/static/`; static URL path remains `/migu-orca-static/`.
- Web API endpoints live in `src/apps/migu_orca_web/views.py` and should reuse existing entry/controller helpers instead of duplicating business rules.
- Existing helpers to reuse where possible: `generate_request`, `apply_ab_submit_action`, `apply_request_save_action`, `load_mikan_config`, `create_mikan_client`, `load_ab_config`, `create_auto_bangumi_http_client`, storage repositories, and request summary/detail helpers.
- Web API Auto Bangumi submit should use request-scoped inline `AutoBangumiConfig`, run through `apply_ab_submit_action`, sanitize `ab_submit_result`, then persist via `apply_request_save_action` so request snapshots and `ab_results/` stay in sync.
- Browser tests live in `tests/browser/`, use `pytestmark = pytest.mark.browser`, temporary storage, and local fake seams; they must not access real MiKan, Auto Bangumi, or qBittorrent by default.
- Web UI browser preferences intentionally persist only `storage_dir` and `save_request`; do not add request-scoped MiKan or Auto Bangumi config to `preferenceKeys`, localStorage, sessionStorage, URLs, or storage JSON.
- Browser tests that route `**/api/v1/requests` must distinguish POST generation from the initial GET list load and continue non-target requests.
- Web UI detail action tests should scope action-entry locators to `.detail-actions`; hidden inline forms can contain submit buttons with overlapping text.
- Web UI explicit AB submit sends request-scoped config in the POST body and may include `storage_dir` in both the query string and body for compatibility; tokens/endpoints must not appear in URLs or browser storage.
- Browser environment uses Chromium / Google Chrome for Testing through Playwright; run `./script/setup-browser-deps.sh` if browser dependencies are missing.
- Validate with `uv run pytest`, `uv run pytest tests/browser -v`, and `uv run python -m compileall -q src`.
