## Codebase Patterns
- Keep learnings about this codebase in this file as iterations progress.
- Ralph defaults to the local Codex CLI; use `./scripts/ralph/ralph.sh` or pass `--tool codex` explicitly.
- Current Ralph Stage 1 PRD is reconciled against `main`; all Stage 1 stories are marked complete after offline CLI and pytest verification.
- Stage 2 Ralph work uses branch `agent/stage2-request-confirmation` and should complete one `passes=false` story per iteration.
- Stage 2 Request confirmation helpers derive in-memory contracts in `request_engine.controllers.request_controller` and should preserve the full Request JSON shape separately from compact views.
- Entry CLI post-generation actions should preserve the existing `success`/`request`/`error` envelope and convert expected business failures with `Stage1Error.as_dict()`.
