## Codebase Patterns

- Python 依赖、检查和测试统一通过 `uv`；前端依赖统一在 `frontend/` 使用 `npm ci`，不得混用 lockfile。
- Stage 27 只通过 `docs/api/openapi.json` 生成 TypeScript 类型/client；不得导入 Python 模型、手写第二套响应 interface 或从旧 `app.js` 复制业务状态机。
- US-198 起类型化客户端由 `openapi-typescript@7.13.0` 生成：`cd frontend && npm run api:generate`
  输出 `src/api/generated/api.ts`（入库），`npm run api:check` 做漂移检查（CI frontend job +
  `tests/api_contract/test_openapi_runtime_consistency.py::test_frontend_generated_client_matches_openapi`
  双守护）。改 `docs/api/openapi.json` 后必须重生成并提交生成文件。
- `_ENDPOINTS` 每个条目必须显式声明可读 `operationId`（如 `listRequests`）；`errors` 声明
  必须与 `extensions/flask_api/api.py:_error_http_status` 运行时分类一致。
  `test_openapi_runtime_consistency.py` 自动核对：声明 vs 分类一致、被分类 error_type 全部有
  声明（CLI-only/批内 item 结果的进 `_UNDOCUMENTED_ERROR_TYPES` 豁免集）、operationId 唯一/
  可读/稳定、OpenAPI 无裸数组属性（列表写 `[Model]` 由 `_normalize_property` 展开）。
- openapi-typescript 生成模块是类型-only（无运行时值）：前端测试用 vitest `expectTypeOf`
  做编译期断言，不能 `import { operations }` 当值用；生成文件无敏感值（字段名除外）。
- 对应 feature 迁移前先补齐它实际读取的深层公开 DTO；长期 `dict[str, Any]` / `Record<string, unknown>` 不能作为完成状态。
- 新前端先挂载 `/app/`；SPA fallback 不能截获 `/api/v1`、海报、`/healthz`、`/readiness`、静态文件或旧 Flask 页面。
- production build 由 Flask 同源提供，不依赖 Node 运行时；Vite dev server 只用于本地开发代理。
- Pinia 只放跨页面非敏感状态且默认不持久化；candidate context、draft ID、搜索结果和敏感表单仅存在于内存。
- endpoint、username、password、token、cookie、Authorization、SID、raw HTML、raw RSS XML、原始响应体、完整失败 URL、magnet、本地绝对路径不得进入 store 持久化、URL、browser storage、日志、build、sourcemap、截图或 trace。
- 未保存草案由服务端 `DraftStore` 权威管理；前端只持有 opaque `draft_id` 和允许 patch，不得提交完整 Request 作为 preview modify/save 权威输入。
- Web storage 只能提交服务端根目录下相对 profile；空值回落服务端根。CLI 显式路径是不同信任边界。
- 单个与批量复用候选、草案、Request 和安全表单组件；不要复制后端标题、季数、筛选、状态或队列规则。

  各自注册、绝不截获。

  `/app/workbench`；RouterLink 不要重复写 `/app/` 前缀。

    - 通知/loading/error-boundary 都是全局非敏感状态：Pinia store 只放计数器/消息，
      不持久化、不含凭据；敏感值仍只在组件内存与单次 POST body。
    - 浏览器测试选导航链接要用 `get_by_role("link", name="订阅方案", exact=True)`：
      `has_text="订阅方案"` 会同时命中「订阅方案工作台」（前缀匹配歧义）。
  - Gotchas encountered
    - App.vue 用了共享组件后必须显式 import（Vue SFC 不会自动注册）；忘了 import 时
      typecheck 会报 unknown component，但 build 也可能悄悄通过——注意看模板编译。
    - 非 JSON 错误体（如代理 502 HTML）之前没置 `nonJson` 标志，测试暴露后补上：
      `envelopeError(status, payload, isNonJson)`。
    - AbortError 同时来自超时与外部取消：用 `signal?.aborted` 区分
      `request_timeout` / `request_cancelled`，两者 status 都是 0。
  - Useful context
    - US-200 将在这套 feedback 原语之上建 layout/button/input/confirm/credential form 等
      primitives；US-202 起迁移 Request 列表时复用 `trackedApi` + 通知 + EmptyState/
      LoadingState/ErrorState。
    - 浏览器测试前置：仓库根 `.migu_orca/storage` 不存在；本机跑浏览器套件需
      `UV_CACHE_DIR=$PWD/.uv-cache` 与 `LD_LIBRARY_PATH=$PWD/.chromium-deps/extracted/...`。
