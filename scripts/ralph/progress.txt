## Codebase Patterns
- Flask `/api/v1` routes use `<path:param>` while OpenAPI uses `{param}`; normalize both forms when checking contract drift.
- `docs/api/openapi.json` is deterministic output from `apps.migu_orca_web.openapi_gen`; regenerate it after changing contract metadata.
- `TrackingRecord` is the external submission authority; legacy queue and AB result data are compatibility projections or migration evidence.
- Public tracking action/status DTOs use finite enums, while request-scoped credentials/capability observations stay out of durable or response contracts.
- Frontend contract fixtures should derive request/response shapes from `frontend/src/api/generated/api.ts`; use type-only assertions instead of feature-local DTO interfaces.
- Legacy queue/AB projections must never resolve `VERIFYING_EXTERNAL` or `RECOVERY_REQUIRED`; only the tracking recovery flow may clear an ambiguous external boundary.
- Versioned persistence readers must fail closed on future schemas and preserve the original artifact; migration is local, idempotent, and must not implicitly upgrade existing JSON.
- Management writes must pass one shared matrix: VERIFIED probe, exact 3.1.18 legacy adapter, and the action/scope/direction-specific capability; recovery keeps the same exact baseline.
- API error envelopes recursively redact upstream evidence by field and value; production error logging must not emit exception tracebacks.
- Release rollback only copies local storage and changes application version; uncertain external operations remain manual and are never automatically replayed.
