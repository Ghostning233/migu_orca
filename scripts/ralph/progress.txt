## Codebase Patterns
- Stage 1 through Stage 4 are complete; archived Ralph records live under `scripts/ralph/archive/`.
- Stage 5 Ralph work uses branch `agent/stage5-real-mikan-source` and should complete one `passes=false` story per iteration.
- Use `uv run pytest` and `uv run python -m compileall -q src` for project quality checks; bare `pytest`/`python` may not be on PATH.
- Preserve the existing top-level JSON result envelope and convert expected business failures with `Stage1Error.as_dict()` or a compatible ErrorResult shape.
- Default CLI request generation must remain offline and fixture-backed unless the user explicitly opts into a real external integration.
- Real external adapters should live behind engine-specific client/transport seams, with tests using injected fake transports instead of live network access.
- The existing static catalog path is `shared.config.DEFAULT_CATALOG_PATH`, loaded through `catalog_engine.controllers.catalog_controller.load_catalog(...)`.
- Catalog matching currently accepts a list of `BangumiCandidate` values and returns both `MatchedBangumi` plus the selected candidate; real MiKan source work should preserve that matching contract.
- Existing `RssSource` values carry `subtitle_group`, `rss_url`, `source_type`, and `fixture_path`; Stage 5 should add real MiKan handling without regressing `source_type=static_fixture`.
- Real MiKan source boundaries live under `src/mikan_engine`; construct clients only from explicit `MikanConfig` loaded by `load_mikan_config(path)`.
- MiKan HTTP reads use the injectable `MikanTransport.get_text(url, *, timeout)` seam; tests should pass fake transports and must not require live MiKanProject access.
- MiKan search URLs are built from explicit `MikanConfig.search_endpoint` by appending a URL-encoded `searchstr` query parameter.
- RSS parsing and filtering live in `rss_engine.controllers.rss_controller`; real RSS HTTP reads should reuse the existing `ParsedRss`, `RssSeed`, and `FilteredRss` contracts.
- CLI AB submission remains an explicit post-confirmation step: use `--action accept --submit-ab --ab-config <path>`; real MiKan opt-in must not implicitly submit to Auto Bangumi.
- Do not include raw HTML, raw RSS XML, complete endpoint URLs, cookies, tokens, or other sensitive config values in structured error details, logs, fixtures, or documentation examples.
