# MiGuOrca Ralph Progress - Stage 26

## Codebase Patterns

- Python 依赖、检查与测试统一通过 `uv`；不要直接使用系统 Python。
- Web API 成功/失败继续使用 `{ok, result}` / `{ok, error_type, error_message, error_data}` envelope；Stage 26 可修正 HTTP 状态，但必须保持 envelope 兼容。
- 先为端点增加 golden contract，再拆分 `views.py`；每次只迁移一个端点族并运行对应 API/浏览器回归。
- Pydantic DTO 与确定性 OpenAPI 是 Stage 27 的公开契约；响应 serializer 使用白名单，不让任意 engine dict 或敏感未知字段穿透。
- Web storage 和 CLI storage 使用不同信任边界：CLI 保留显式路径，Web 只能使用服务端允许根目录/profile。
- 未保存草案由服务端权威 draft 管理；客户端只持有 opaque ID 和允许 patch，不能把完整 Request 作为可信持久化输入。
- 外部 endpoint、username、password、token、cookie、Authorization、SID、raw HTML、raw RSS XML、原始响应体、完整失败 URL、magnet 和本地绝对路径不得进入 API 展示、storage、URL、browser storage、日志、截图或 trace。
- UI story 必须读取 `.agents/skills/dev-browser/SKILL.md` 并用真实 Chromium 验证；浏览器整体 skip 不能作为 UI 完成证据。
- 浏览器测试使用 fixture/Playwright route 隔离外部服务；不得自动向真实 AutoBangumi、qBittorrent 或 MiKan 执行写操作。
- 完整 browser/full pytest 前确认仓库根 `.migu_orca/storage` 不存在，避免陈旧 Request 干扰测试。
- Stage 26 不做页面视觉重构或引入新前端框架；只允许维持 API 兼容所需的最小旧前端修改。
- API 端点清单与 golden contract 测试位于 `docs/api/endpoint_inventory.md` + `tests/api_contract/`；新增/删除 `/api/v1` 端点必须同步这两处，否则 `test_inventory_consistency.py` 失败。
- 旧前端 `static/app.js` 的 localStorage key 只有 `miguOrca.web.storageDir`/`miguOrca.web.saveRequest`，URL 状态参数只有 `request_id`/`batch_id`；`tests/api_contract/test_frontend_dependencies.py` 冻结了这些契约。
- `GET /api/v1/mikan/posters/<key>` 是函数视图，不经过 `APIBaseView` envelope 包装；其 `Stage1Error`（`invalid_poster_key`/`poster_not_found` 等）在 TESTING 模式直接上抛、非 TESTING 变成 Flask 500 HTML。US-192 修正 HTTP 状态时需把它纳入统一错误处理。
- 批量 retry/recover 对「队列不存在」返回 `queue_not_found`（`load_submission_queue` 直接抛），对「队列存在但 request_id 未知」才返回 `queue_item_not_found`。
- OpenAPI 契约在 `docs/api/openapi.json`，由 `uv run migu-orca-openapi` 确定性生成（`--check` 做漂移检查）；端点注册表在 `src/apps/migu_orca_web/openapi_gen.py` 的 `_ENDPOINTS`，新增/删除 `/api/v1` 端点必须同步注册表，否则 `tests/api_contract/test_openapi_generation.py` 失败。
- 公开响应 DTO 在 `src/apps/migu_orca_web/api_contract.py`，全部 `extra="forbid"`；`_ENDPOINTS` 的 `success` 字段引用 DTO（或少量内联 dict，如 request list）。
- pydantic v2 `model_json_schema()` 会输出 `$defs` + `$ref`；OpenAPI 生成时用 `_dereference` 内联，避免输出带本地 ref 的文档（客户端生成器更易消费）。
