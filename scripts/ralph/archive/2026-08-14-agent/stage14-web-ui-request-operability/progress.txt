# Ralph Progress Log
## Codebase Patterns
- Browser tests that trigger Request generation should seed `miguOrca.web.storageDir` to a temporary fixture path before visiting `/index`; otherwise default `.migu_orca/storage` can be polluted and empty-list tests become order-dependent.
- Explicit `miguOrca.web.saveRequest = "false"` is preview-only on `/index`; preview details must stay read-only, avoid URL `request_id` sync, and offer a save action before saved Request APIs are available.
- Request detail seed feedback should derive valid/excluded lists from the selected `source_info.rss_sources` entry; `confirmable_config.effective_seed_names` is only the selected valid list and does not include exclusion reasons.
- Selected RSS source summaries should carry safe title-only `seed_names` for the complete pre-filter Seeds list; use valid/excluded title fallback only for older saved Requests.
- qBittorrent Settings connection testing is direct-rendered in `#settings-qbittorrent-test-form`; do not wrap it in `<details>`/`<summary>` or require tests to open a disclosure before filling fields.
- Stage closeout docs should update README, `docs/backlog.md`, `docs/MiGuOrca_main_PRD.md`, the stage PRD, and affected module PRDs together so the current-stage baseline stays consistent.
- Sensitive Web UI regressions should check URL state, `localStorage`, `sessionStorage`, visible body text, and saved Request JSON; qBittorrent and Auto Bangumi secrets are allowed only in explicit request bodies.
