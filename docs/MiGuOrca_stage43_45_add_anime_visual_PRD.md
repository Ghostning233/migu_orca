## 2. 目标、共同 AC 与非目标

用户在每个画面能够识别当前任务、修改是否生效、确认阻断及恢复方式、此次保存集合。
成功以可观察行为和桌面布局验收，不承诺未经测量的效率百分比或逐像素复刻。

| 维度 | 所有故事必须满足的验收要求 |
| --- | --- |
| 主链路 | 名称输入 → 用户人工选择真实合集 → 服务端草案审核 → 本地保存确认 → 追番管理再次显式确认外部提交 |
| 候选 | 唯一候选不自动选择；CONFLICT 继续禁止选择；NEEDS_CONFIRMATION 继续要求明确确认，不照搬外部分析的放行描述 |
| 权威 | 只用生成契约允许的能力/服务端 revision/patch；不回传完整 Request 当权威，不自行递增版本 |
| 两种批量确认 | 持续保留 N 部和确认全部；全部范围是完整批次的全部当前可确认项，与筛选/勾选无关；N 的隐藏项口径待 D-02 |
| 反馈 | 字段错误、候选失败、草案阻断、部分成功、未知结果及恢复常驻原业务区域；Toast 仅补充摘要 |
| 数据 | 总集数未知显示未知；已更新集数显示待开发，不从资源推算；缺封面/季度不由前端增加阻断 |
| 安全 | 禁止 RSS URL、magnet、Cookie、凭据、原始响应、绝对路径、完整 Request、草案能力或未白名单字段进入展示、隐藏属性、URL/history、浏览器存储、console、截图/trace |
| 桌面 | 1280×720、1440×900、1920×1080、桌面 200% 缩放；长标题、空结果、无资源及部分成功均可操作 |
| 无障碍 | 可见标签与错误关联；焦点环不被裁剪；中文状态不只靠颜色；主要目标至少 44×44；正文对比度至少 4.5:1、控件边界至少 3:1 |
| 动效/焦点 | reduced-motion 取消非必要位移/平滑滚动，保留进行文字；重算和 Toast 不抢焦点；弹窗 trap、Escape 与关闭恢复焦点 |
| 生命周期 | 未保存现场只在内存，保留应用内离开/原生刷新警告，不承诺跨刷新恢复 |

共同非目标：新 API/公开字段、数据库、后台 worker、多用户、移动端、下载器、外部写流程、
未保存会话持久化、单项批量重搜、伪百分比/逐条实时进度、默认分页/虚拟滚动、品牌重设计。
纯视觉改动不修改业务成功判断；如能力缺失，使用缺省/省略或单独立项，不造 mock 字段。

## 5. Stage 44 候选执行范围

以下是后续 PRD 必须承接的故事和 AC；不是可直接执行的独立 Stage 44 PRD。

### WP-44-A：合集身份、筛选与资源关联

用户故事：先核对真实合集，再比较输入与资源结果。

验收标准：

1. 默认顺序为已选合集 → 字幕/筛选与资源 → 确认条件；不重复标题、同口径规则或计数。
2. 批量宿主保留用户实际选中的公开候选摘要并传入共享编辑器；不从解析/别名推断季度。
3. 直连或摘要缺失时显示未提供/未知；封面仅用已有安全代理来源，否则占位。
4. 包含/排除与结果相邻，1280 可重排，200% 缩放纵向可达。
5. 有效数对应当前选中字幕组；排除数来自该来源排除列表；完整数对应现有分组标题集合；不得相减推算。
6. 默认安全样例数量按 D-03；完整列表按需展开，字幕组一级、组内标题二级缩进。
7. 正则/大小写/目录按需展开；清除字段、校验、恢复仍可达。
8. 未保存全部信息逐字段投影，移除英文实现分区与实现术语；不调用 safe-info，不对象 dump。
9. 已保存模式保留人工保存及原安全边界，不误接草案自动请求。

### WP-44-B：修改状态与单番最终确认层级

用户故事：理解临时修改与本地保存确认的差异，先审核再确认。

验收标准：

1. 保存修改为次操作，说明仅更新本次草案，无待修改时禁用。
2. 单番最终确认位于审核内容之后，附近显示同源阻断原因、本地保存说明。
3. 批量详情不增加最终保存按钮，最终动作由固定栏承载。
4. 改产品文案不改资格/错误分类；已保存待确认、定位待核验和错误面板留在确认业务区。
5. 不创建第二 session/scheduler，不用 revision 改 key 重挂载。

下表同时是两包的资源、动作和恢复矩阵：

| 状态 | 展示 | 操作/恢复 |
| --- | --- | --- |
| 一致无待编辑 | 当前服务端结果 | 修改禁用，无阻断可确认 |
| 防抖/目录等待 | 待生效输入与上次结果明确区分 | 可保存修改，确认禁用 |
| 重算在途/继续输入 | 一致结果及最新待处理意图 | 同草案防重，不并发复用 revision |
| 成功 | 配置、资源、版本原子更新 | 按最新结果恢复 |
| 可恢复失败 | 新意图未生效 | 既有重试/恢复，确认禁用 |
| 零资源/字段阻断 | 最新零资源或具体问题 | 就近修正，不沿用旧有效数 |
| 冲突/失效 | 不再称为可确认草案 | 重新选择/生成，不猜版本重放 |
| 保存中/未知 | 保留审核及常驻结果 | 防重，原操作恢复 |
| 已保存确认失败 | 明确已保存 | 对 saved Request 重试确认 |
| 已确认未定位 | 确认与定位状态分离 | 既有只读定位/打开管理 |

## 6. Stage 45 候选执行范围

### WP-45-A：紧凑列表与查看/勾选分离

用户故事：快速定位待处理项，分清右栏查看项与保存集合。

验收标准：

1. 默认左卡突出标题、中文状态、必要阻断/错误和下一步；别名/偏好等辅助信息按需展开。
2. 紧凑不隐藏关键失败、未生效、未知结果及恢复动作。
3. 查看仅改变右栏；复选框仅改变确认集合，名称明确为勾选待确认。
4. 保留快捷字幕组编辑与右栏同源状态；修复不自动跳位，显式排序才重排。
5. 筛选保留数据/勾选，隐藏当前项仍保留右栏与清除筛选入口。
6. 下一异常先可见化再定位/查看/聚焦；1/12/36 连续列表，无分页/默认虚拟滚动。
7. 1440×900 的 12 项普通短标题夹具至少同屏呈现三张完整卡；长错误允许自然增长。

| 状态 | 展示/恢复 |
| --- | --- |
| 待选合集 | 明确下一步，不能勾选确认 |
| 可确认草案 | 查看态与勾选态分别可辨 |
| 已勾选项重算/阻断 | 保留意图，排除资格并说明 |
| 当前详情被隐藏 | 右栏保留，清除筛选可达 |
| 筛选无匹配 | 筛选空态，不冒充批次为空 |
| 单项失败/未知 | 原位结果和真实恢复入口 |

失败/无障碍：卡片快捷键不截获内部表单按键；读屏分别识别查看/勾选；焦点环不裁剪；
删除临时卡后落下一条、上一条或列表标题，不丢到页面根。

### WP-45-B：固定栏与两种确认范围

用户故事：点击前与二次确认时都清楚此次保存哪些方案。

验收标准：

1. N 部是强主操作，确认全部是持续可见次操作，不藏更多菜单。
2. 完整批次、当前可见、已勾选/可确认与需处理计数分组呈现，标明作用域。
3. 全部复用 Stage 43 完整批次资格；可见项全选只改变可见勾选；N 按 D-02。
4. 按钮、弹窗数量/安全清单、描述符与 item_ids 一致；列明隐藏参与与排除情况、本地/外部边界。
5. 弹窗期间资格或版本变化必须重新确认；发送后冻结意图，后续筛选不能改写。
6. 无勾选、勾选项阻断、全批无资格、保存中和待核验分别给可见禁用原因，不靠 title。
7. 按实际底栏换行高度留空间，最后卡片、字段、错误可滚到无遮挡区域；模态/下拉/Toast 层级正确。

| 状态 | N 部 | 全部 |
| --- | --- | --- |
| 无勾选、有资格 | 禁用说明 | 完整批次 M 项可用 |
| 手工勾选 | 按 D-02 集合 | 独立完整批次 M 项 |
| 部分勾选项阻断 | 排除无资格并解释 | 同样排除无资格 |
| 可见零项、隐藏有资格 | 按 D-02 | 全部仍可用 |
| 弹窗状态变化 | 重新确认 | 重新确认 |
| 保存中/未知 | 防重 | 原冻结意图恢复，不新起全部意图 |

无障碍：按钮数量不替代范围说明；trap/Escape/关闭恢复复用 ConfirmDialog；
缩放底栏全操作可达，背景在模态期间不可交互。

### WP-45-C：部分成功、未知结果与完成导航

用户故事：识别成功和剩余工作，安全继续审核。

验收标准：

1. 以 results[] 判业务结果，常驻汇总区分本次结果与完整批次剩余工作，不只 Toast。
2. 成功项退出可确认集合，保留待提交及管理入口，不重复保存、不回滚成功。
3. 失败原位保留，首个失败被隐藏时先可见化再聚焦。
4. 确定失败、失效、已保存待确认、未知分别走既有恢复；畸形 200 不部分应用后宣称完成。
5. 未知继续使用原 body/key/revision/集合；失败重试排除成功项。
6. 无失败但有未处理项留页定位首项；全部完成按 D-04；定位只用真实公开 tracking 标识。
7. 定位未完成不得伪造关联；只补展示/焦点/批准导航，不改保存协调器或外部写。

| 结果 | 常驻反馈/恢复 |
| --- | --- |
| 全部成功无剩余 | 明确完成，按 D-04 导航/留页 |
| 所选成功仍有剩余 | 留页，首个未处理 |
