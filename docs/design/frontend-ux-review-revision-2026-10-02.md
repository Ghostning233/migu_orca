## 当前设计决定

- 批量选择合集后的草案右栏增加内边距，桌面以 24px、窄屏以 16px 为实现起点；最终值通过
  真实页面测量和人工审核记录，不把该起点写成获批金样或已有测量。
- 资源结果标题下的四项信息、安全样例与完整列表入口，装入与“字幕与筛选”一致的描边盒子，
  使用一致的背景、圆角和内边距；移除资源区域无设计依据的横/竖分割线。
- 高级设置默认折叠，正则、大小写敏感与目录字段展开后布局紧凑、文字对齐，使用共享复选框。
- “查看完整资源列表”使用现行 primary 蓝色；悬停淡蓝圆角背景，键盘有可见焦点；保持按钮
  打开双页签弹窗的语义及关闭后焦点/滚动恢复。
- 标题搜索浮层包括独立背景、内边距、阴影、输入框和明确关闭按钮。删除自定义清空按钮，
  避免浏览器原生搜索清除图标产生第二个叉；不得以输入框边框代替整个浮层背景。
- 点击关闭、Esc 或再次点击放大镜收起；关键词、筛选及活动标记保留，焦点回放大镜。
  用户手动删空关键词恢复标题范围；状态筛选与只看需处理仍通过各自控件恢复默认。
- 删除“清除条件”“下一异常”及其预留空间与专用死逻辑。状态与短提示优先同排；窄屏可换行，
  失败原因与唯一恢复动作不能为追求一行而删除、截断或隐藏。
- 批量搜索首屏相关控件居中，保留现有正确选中色，不照搬设计图错误颜色。单番/批量空闲态
  共用标题层级、中心轴和模式切换锚点（相同视口偏差不超过 2 CSS px）；输入形态保留差异。
- 全站复选框单独在 #156 落地：以 18px 方框为实现起点，可见方框与点击区域分离，保留
  当前 primary 色；覆盖单/多行标签、checked、unchecked、indeterminate、disabled、hover、
  focus-visible、原生键盘操作和标签关联。最终尺寸需人工验收，不顺带重做 switch/radio。
- 批量底栏全选文字、计数和按钮对齐；全选继续仅作用于当前可见可确认项，隐藏勾选不丢失。

## 截图与实际页面一致性

本轮只读核对发现当前标题搜索模板只有显式清空按钮，无独立关闭按钮；输入框为
`type="search"`。浏览器原生清除图标是两叉的可能解释，未证明其实际来源。
截图通过真实应用与安全 mock 数据生成，未发现增造关闭按钮；现有构建前置只检查
`dist/index.html` 是否存在，没有源码/构建新鲜度证明。

#155 必须建立：最新前端构建 → 限定源码指纹与产物标识 → 实际加载资源校验 → 真实动作
→ 截图及安全证据清单 → 同产物交互预览。dirty 工作区允许验证，但须标识精确输入；源码或
产物变化使旧证据失效。清单不包含运行数据、凭据、原始响应或本地绝对路径。
截图稳定 CSS 的影响需明确，正常动效与 reduced-motion 另行验收；不复制一套专供截图的 UI。

- 保留人工选择、草案权威、保存/外部提交两次确认、revision/幂等、部分成功/结果未知恢复、
