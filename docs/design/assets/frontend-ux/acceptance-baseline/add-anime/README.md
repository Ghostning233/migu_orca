# 添加番剧视觉回归基准（#139／#140～#144）

本目录是「添加番剧」页面族在**真实 Chromium** 上渲染并审核通过后的视觉回归基准。
基准不是设计位图，也不是运行产物：它们是固定 fixture 下的页面截图，用于让「明显像素
偏差、关键几何偏差」自动失败。

## 文件

| 文件 | 场景 |
| --- | --- |
| `single-search.png` | 单番搜索首屏（输入与模式切换） |
| `single-candidates-four.png` | 单番四张候选卡工作台 |
| `single-draft-review.png` | 单番未保存草案审核（长内容单轴滚动） |
| `batch-candidates.png` | 批量候选工作台（12 部 + 右栏横向合集候选卡） |
| `batch-candidate-loading.png` | 批量右栏当前候选加载 |
| `anchors.json` | 每个场景的关键锚点实测几何（门禁目标，容差 ≤2 CSS px） |

## 门禁口径（已冻结）

- 画布与 fixture：1440×900、reduced-motion、隔离存储、mock 外部依赖、确定性文案与
  海报 fixture（`tests/browser/add_anime_visual_fixtures.py`）。
- 任一 RGB 通道差值 >12 计为显著差异像素，显著差异比例必须 **≤0.5%**。
- 具名动态掩码总面积 **≤5%**；当前五个场景都**不使用掩码**（实际 0%）。
- 关键锚点与尺寸偏差 **≤2 CSS px**。
- 同一场景连续三次截图必须稳定（`test_add_anime_scene_captures_are_stable`）。
- 缺基准即失败，不会静默生成；门槛不得按单次 PR 反向调宽。

## 记录与替换

```bash
MIGU_ORCA_RECORD_VISUAL_BASELINE=1 \
  uv run pytest tests/browser/test_app_add_anime_visual.py -q
```

替换基准必须**与实现改动分开审阅**：先由用户审核真实浏览器画面（本轮由具备读图能力的
Agent 按用户要求执行并留痕），再记录；不得用整卡掩码、删除断言或直接更新金样来让失败
用例转绿。
