## 1. 布局与滚动

| 量 | 值 | 来源 |
| --- | --- | --- |
| 页面外壳 | 沿用一级页面容器（壳层档位内边距，导航与状态总览留在滚动区外） | 壳层基线 |
| 状态总览 | 固定**四类**卡片（待处理／追番中／需处理／已停用）+ 服务端分类计数，位于工作台之上，不随列表/详情滚动 | #218 A2；取代 #85/#99 的五项语义 |
| 双栏 | `minmax(0, 3fr)` / `minmax(18rem, 2fr)`，间距 `--space-5` | 既有页面几何 |
| 列表/详情可用高度 | 两栏**等高**，共同占用视口剩余高度（导航、页头、状态总览与模块外反馈之外的部分）；下限 `320px` | #218 B3/B4；取代旧的 `clamp(320px, calc(100vh - 420px), 640px)` 与 420px chrome 余量 |
| 列表滚动 | 列表容器 `overflow-y: auto`、`overscroll-behavior: contain`；标题行、批量工具栏与工具状态区计入左栏总高（#225 起不再有筛选行） | 长列表只在栏内滚动 |
| 详情滚动 | `.tracking-inspector`：与列表同高、`overflow-y: auto`、`overscroll-behavior: contain`；#225 起两栏共同占满剩余高度，不再使用桌面 `sticky` | 长详情只在栏内滚动 |
| 低高度降级 | 视口高度不足以容纳两栏各自 `320px` 保底时，**允许整页滚动**作为降级；这是「无整页滚动」承诺的边界。视口高度 ≤640px 时列表面板整体滚动、列表不再二次内滚，批量工具栏/状态区不会把列表压到 0 | #218 B4；#225 |
| 窄视口 | `max-width: 760px` 时按壳层纵向重排，栏高降为 320px，详情不再 sticky；不再使用页面自造的 800px 断点 | 壳层基线 `main.css:454`；#218 B2 |

列表达到可用高度后整页不再增长；展开记录、操作记录或诊断只改变栏内滚动位置，
另一列与状态总览的屏幕位置保持不变。

## 2. 状态与占位

- 代表状态「追番中／待提交／结果待确认」与提交前复核失败继续使用既有服务端安全投影的中文摘要，不合并成统一警告。
- 总集数与「已更新集数」在无可信服务端值时都显示「未开发」（Issue #131/#165），绝不从有效资源数、种子、RSS 或下载数量推断。
- 状态、允许动作与作用范围全部来自服务端投影；未知值 fail closed，不显示外部 ID、完整 RSS URL 或秘密。

## 3. 外部写的连接门控（Issue 116）

| 状态 | 行为 |
| --- | --- |
| 无已保存 AB 连接或所需凭据 | 「提交方案」「重试提交」、批量提交、修改／启停／刷新／删除外部订阅**可见但禁用**，原处提示「先在设置中连接 Auto Bangumi；缺少已保存连接时不会发起任何外部写。」不弹确认、不发请求 |
| 已有已保存连接 | 一律可用；最近一次探测失败或能力诊断为空**不**作为前端准入门槛，由服务端在请求内复核连接、认证、精确版本与能力 |
| 纯本地操作 | 修改本地方案、本地复核等不依赖连接，继续可用 |
| 结果待确认／未决外部意图 | 只提供**只读核验**（自动前置、可一键重试）、**主动重发**（独立风险确认，ADR-0002）与**放弃跟踪并删除**（仅本地，ADR-0006）；「自动恢复」「标记为成功／失败」已退役。只读核验需要已保存连接 | #218 E5/E6/E7 |

**两种「按钮不可用」必须区分**（#218 D3）：服务端 `available_actions` **不允许**该动作时**不渲染**按钮；服务端允许但**缺已保存连接**时**渲染并禁用**，原处提示去设置连接。不得因为最近一次探测失败就把已允许的动作隐藏或删除。

危险操作保留显式确认：删除追番方案默认**仅删本地**（Auto Bangumi 订阅继续运行），勾选时才同时删除受控外部订阅；请求固定 `file=false`，绝不删除已下载媒体。独立「只删外部、保留本地」动作及其公开端点已退役（#218 E4；ADR-0006）。
