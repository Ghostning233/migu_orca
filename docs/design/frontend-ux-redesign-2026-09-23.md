### 本轮提示词摘要

- 共同约束：桌面高保真 UI 效果图；暖白 `#F7F8FA`、深海蓝 `#0B2A55`、少量珊瑚橙 `#D9431F`；顶部固定「添加番剧／我的追番／设置」三项导航；中文可读、轻边框和弱阴影；不得出现第四项导航、技术 ID、秘密、完整 URL、磁力链接、绝对路径、版权番剧图、浏览器边框或水印。
- 单番首屏：全屏居中的单一搜索任务、模式切换、完整单行输入与三步预告；首次进入不显示结果或装饰性大幅插画。
- 批量候选工作台：搜索首屏下方的第二屏；约 36% 条目列表与 64% 当前详情；独立勾选和当前行高亮；候选只显示封面、标题、季度证据、总集数与选择动作，不显示资源数或虚构简介。
- 追番中：五类状态、左列表右详情；已选条目展示安全摘要；修改外部订阅、暂停和刷新作为并列次操作，更多操作与诊断折叠。
- 滚动修订：批量工作台左栏和右栏、我的追番列表和详情分别拥有可见的内部纵向滚动条；页面标题、状态总览和底部批量操作栏留在滚动容器外。
- 单番补图：四候选必须一行居中；1～4 项对照保持卡片同宽；被点击候选就地加载且其余候选暂禁；草案审核才显示资源数；失败和无候选均在搜索首屏保留输入并就地恢复。
- 批量补图：首屏保留多行输入；进度以已完成部数分段且不预估未完成项；候选和草案共用独立滚动的左右工作台；部分成功只对失败项提供重试，成功项转待提交。
- 追番补图：追番中三项管理操作并列；待提交突出「提交方案」；结果未知突出先核验且不能重复提交；复核失败明确尚未创建外部订阅并返回修改方案。
- 设置与弹窗补图：默认偏好、存储、连接依次分组；连接编辑输入为空且不回显已保存秘密；提交方式弹窗按「取消／下载现有资源／持续追番」排列，取消有初始焦点；重搜与删除弹窗清楚说明影响范围。

## 添加番剧的已确认方向

- 单番和批量都使用独占一屏的搜索首屏，并保留完整输入框。
- 搜索成功后，候选或审核工作台位于下方第二屏；页面通过纵向整屏滚动／吸附在搜索首屏与工作台屏之间切换。在模块外空白处向上滚动或点击「返回搜索首屏」可返回输入区，不另设「修改搜索」概念。
- 单番候选使用居中的卡片网格。1～4 个合集均在同一行内居中展示；卡片不提前展示草案阶段才有的有效资源数。
- 批量搜索完成后的工作台同样位于第二屏，搜索输入保留在第一屏。
- 「全屏封面首屏」指占满一屏、聚焦搜索任务的入口；不以大幅插画或背景为前提。番剧封面展示在候选与详情中。
- 两屏交界处轻柔吸附；整页纵向滚动只负责搜索首屏与工作台屏的切换。工作台屏不因长内容增长，批量左侧条目列表和右侧候选／草案详情各有独立、可见的纵向滚动条；顶部页面标题和底部操作栏保持在工作台屏内。
- 搜索结果就绪后自动进入工作台屏，并将键盘焦点移到结果标题。工作台屏保留「返回搜索首屏」按钮。
- 返回首屏修改输入不会立即清除第二屏。重新搜索若会替换未保存工作，先用简短提示说明「下方未保存的修改会被清除」；取消则保持现场。
- 单番选择合集后，第二屏从候选选择切换为草案审核，不另开第三屏；「重新选择合集」返回第二屏候选状态。
- 批量工作台在第二屏保持左侧条目列表、右侧当前条目详情；右侧随条目阶段显示候选选择或草案审核。当前查看项和勾选参加保存的条目使用不同控件与视觉状态。
- 单番候选主图展示四张同排，另以布局对照图核对 1～4 张的居中效果；卡片有稳定最大宽度，不为填满行宽而拉伸。

## 我的追番与设置的已确认方向

- 追番详情按当前条目状态突出一个最相关的主操作；常用次操作分组，危险操作和技术诊断收起。失败或结果未知时提升相应恢复动作。
- 追番总览制作「追番中」「待提交」「结果未知／需处理」三张代表图，另以局部状态补图呈现提交前复核失败。追番中默认展示运行状态与方案摘要，修改、暂停和刷新放在同一管理操作组，不强行选其中一个作为常设强主按钮。
- 我的追番页面本身不随列表或详情展开而增长。番剧列表与追番详情分别占据视口中的固定可用高度，各有独立、可见的纵向滚动条；导航、页面标题和状态总览留在模块外，避免整页随内容随意滚动。
- 设置页制作新版整体设计，顺序为「默认偏好 → 存储设置 → Auto Bangumi 连接状态与操作」。连接只在首次或变更时常用，不占首页顶部；配置与安全规则不变。
- 设置页目标图移除独立「高级诊断」区。当前代码仅在折叠面板内展示静态客户端名称和一条连接能力说明；连接测试结果放入连接卡片，提交失败诊断留在对应追番详情。
- 设置首页先展示「默认偏好、存储设置、Auto Bangumi 连接」三个分组摘要。默认偏好排第一，展开后按字幕组、过滤、命名分段编辑；存储与连接在各自分组内编辑。

## 搜索反馈的已确认方向

- 搜索失败、搜索成功但无候选都在搜索首屏就地提示与重试。无候选时优先请用户核对关键词；已有 MiKan 合集链接／编号的直连救援入口保留，但默认收起。
- 批量搜索目标图使用按输入部数分段的真实进度条。找到候选、无候选、单部失败都算该部处理完成并推进一格；动画仅平滑到已完成位置，不预估未完成进度。
- 当前 `POST /api/v1/batches/parse` 只在整批完成后返回。后续实现需新增逐部完成事件或等价进度契约；设计图不得将时间估算误写为真实进度。

## 滚动边界与验图

- 我的追番：列表和详情同时很长时，两列可分别滚到底，另一列位置不变；展开追番详情里的操作、记录或诊断不会增加页面高度。
- 批量工作台：左栏 36 部与右栏长草案可分别滚动；右栏展开高级字段时不推动左栏或底部操作栏；固定操作栏不得遮住任一栏的末项。
- 单番工作台：候选或草案内容超出第二屏可用高度时，在该屏的内容面板内滚动；不靠增加整页高度容纳高级字段。
- 添加番剧：搜索首屏与工作台屏仍是纵向整屏切换；工作台模块内的滚轮／触控板滚动始终只作用于所在模块，即使模块已到顶部或底部也不触发整页切屏。只有模块外的空白区域滚动或「返回搜索首屏」按钮用于切回首屏；单番、批量工作台遵守同一边界。
- 滚动条应有可见轨道与滑块，鼠标滚轮、触控板、键盘与缩减动态效果均可到达相同内容；图中只表达布局和滚动边界，不以截图证明实际交互已实现。
