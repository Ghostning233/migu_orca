## 3. 字体

### 3.1 字体族

```text
Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif
```

不依赖在线字体才能完成首屏。数字使用等宽数字特性（`font-variant-numeric: tabular-nums`）以
减少状态计数跳动。

### 3.2 字号与行高

| Token | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--type-display` | `40px / 1.2` | 700 | 单番首页主标题；其他页面禁用 |
| `--type-page-title` | `28px / 1.3` | 700 | 一级页面标题 |
| `--type-section-title` | `20px / 1.4` | 650 | 卡片组、详情区标题 |
| `--type-card-title` | `17px / 1.4` | 650 | 番剧标题 |
| `--type-body` | `15px / 1.6` | 400 | 默认正文、表单值 |
| `--type-label` | `14px / 1.5` | 550 | 字段标签、按钮、状态标签 |
| `--type-caption` | `12px / 1.5` | 400 | 时间与补充说明；不承载关键错误 |

中文正文不使用全大写、过宽字距或小于 12 px 的字号。可点击控件不得仅靠 12 px 文字表达。

## 6. 桌面布局

### 6.1 宽度档位

| 档位 | 视口 | 页面水平内边距 | 行为 |
| --- | --- | --- | --- |
| 紧凑桌面 | `1280～1439px` | `24px` | 收窄左栏与间距，不隐藏主字段或主操作 |
| 标准桌面 | `1440～1679px` | `32px` | 主要设计与浏览器验收基线 |
| 宽桌面 | `1680～1920px` | `48px` | 限制行长，额外空间优先给详情，不无限拉伸列表 |

本轮不定义低于 1280 px 的移动/平板产品布局。普通窄窗口可以显示明确的桌面宽度提示；但在
桌面浏览器 200% 缩放等无障碍场景中，必须允许双栏纵向重排并保持全部字段和操作可达，不能只
显示宽度提示。该重排是桌面无障碍行为，不代表移动端功能已经交付。

### 6.2 壳层和内容

| Token | 值 |
| --- | --- |
| `--top-nav-height` | `72px` |
| `--content-max` | `1512px` |
| `--content-gap` | `24px` |
| `--batch-list-min` | `360px` |
| `--batch-list-max` | `460px` |
| `--detail-min` | `640px` |
| `--inspector-min` | `400px` |
| `--inspector-max` | `520px` |

- 批量审核列表约占可用内容宽度 34%～38%，详情约占 62%～66%。
- 我的追番列表约占 58%～64%，右侧检查器约占 36%～42%。
- 左右栏之间使用 24 px 间距和独立边界，不使用拖拽分栏；用户不需要管理布局。
- 详情与检查器使用 `position: sticky` 的等价行为，顶部避开导航，底部避开固定操作栏。
- 卡片封面建议使用 3:4 比例；批量紧凑封面约 72 × 96 px，详情封面约 160 × 214 px。

## 7. 组件视觉状态

### 7.1 按钮

- Primary：深海蓝底、白字；每个可见区域最多一个强主操作。
- Secondary：白底、强边框、深色文字。
- Ghost：透明底，用于“返回”“展开”等低影响操作。
- Danger：危险色只在二次确认弹窗的最终按钮使用，不能与普通失败提示混用。
- Loading：保留原宽度，显示进度并防重复，不把文字替换成只有旋转图标。
- Disabled：降低对比但仍可识别；旁边必须有禁用原因，不只依赖悬停提示。

### 7.2 列表、卡片与状态徽标

- 当前查看项：`--color-surface-selected` 背景、主色边界或左侧 4 px 指示条。
- 批量勾选：使用独立复选框，不能和“当前查看项”的整卡高亮混为一个状态。
- 我的追番：只使用单选行高亮/指示条，不显示复选框或批量删除入口。
- 状态徽标：圆角胶囊、状态文字和图标组合；不得只显示红/绿圆点。
- 失败卡片：错误摘要保留在条目附近；整张卡不铺满高饱和红色。

### 7.3 表单与反馈

- 字段标签始终可见，不能只使用 placeholder。
- 错误文字紧邻字段并与控件通过可编程描述关联。
- 页面级提示采用弱背景、左侧状态图标和可关闭/处理动作；关键错误不自动消失。
- Toast 只用于非关键完成提示，不承担失败恢复入口。
- 骨架屏保持真实布局；已有内容更新时优先保留内容并叠加“正在更新”。

## 8. 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `--motion-fast` | `120ms` | 悬停、按下、焦点反馈 |
| `--motion-base` | `180ms` | 分段滑块、展开收起 |
| `--motion-slow` | `240ms` | 页面内详情替换、提示进入 |
| `--ease-standard` | `cubic-bezier(.2,0,0,1)` | 普通过渡 |
| `--ease-emphasized` | `cubic-bezier(.2,.8,.2,1)` | 分段滑块与定位提示 |

- 模式滑块移动不超过 180 ms；点击和键盘激活使用同一动画。
- 切换批量当前卡片时详情使用短淡入，不做横向页面滑动，不闪现旧字段与新标题的组合。
- 异常修复后卡片不自动移动；显式重排才使用位置变化动画。
- `prefers-reduced-motion` 下取消位移、平滑滚动、呼吸高亮和非必要骨架动画，保留即时选中态。

## 9. 焦点与层级

| Token | 值 |
| --- | --- |
| `--focus-ring` | `0 0 0 3px rgba(37,99,235,.32)` |
| `--z-nav` | `20` |
| `--z-sticky-action` | `30` |
| `--z-popover` | `40` |
| `--z-modal-backdrop` | `50` |
| `--z-modal` | `60` |
| `--z-toast` | `70` |

焦点环不能被容器 `overflow` 裁剪。弹窗开启时背景不可交互；关闭后焦点返回触发按钮。固定操作
栏不能覆盖弹窗、下拉菜单或错误提示。

## 11. 实现与验收约束

1. 先在共享主题层定义 Token，再实现页面；禁止逐页复制相同常量。
2. 状态色、按钮、输入框、卡片、提示和弹窗必须通过共享组件消费语义 Token。
3. 浏览器验收至少覆盖 1280 × 720、1440 × 900、1920 × 1080 和 200% 页面缩放。
4. 自动化颜色检查不能替代键盘、读屏、缩减动画和真实页面可读性检查。
5. 如果实现 Agent 发现 Token 无法满足已冻结交互或对比度要求，应提交设计变更说明，不得静默
   使用局部魔法值。
