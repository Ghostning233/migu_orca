# M13 Web UI / 管理界面模块 PRD

## 1. 模块目标

M13 负责后续阶段的 Web UI 或管理界面能力，用于展示 Request、执行确认操作、管理配置和查看历史记录。

第一阶段不实现 Web UI。

## 2. 模块边界

本模块负责：

1. 展示 Request 列表和详情。
2. 展示源信息、候选 RSS、有效种子和排除原因。
3. 提供接受、修改、取消操作入口。
4. 展示 AB 提交结果和降级配置。
5. 提供用户偏好和规则配置入口。
6. 展示日志摘要或错误信息。

本模块不负责：

1. Request 生成业务逻辑。
2. 种子筛选规则。
3. AB 调用。
4. 持久化底层实现。
5. 用户认证系统，除非后续明确纳入范围。

## 3. 后续能力规划

Web UI 后续可以支持：

1. 单番剧 Request 生成表单。
2. Request 详情确认页。
3. 字幕组和筛选规则调整。
4. 文件夹名预览和编辑。
5. AB 提交结果展示。
6. 降级 JSON 下载。
7. 历史 Request 查询。
8. 用户偏好配置管理。
