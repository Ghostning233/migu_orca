# M11 存储与状态管理模块 PRD

## 1. 模块目标

M11 负责后续阶段的 Request、状态历史、用户操作历史、AB 调用结果和降级配置的持久化。

第一阶段不实现本模块。第一阶段如需保存输出，只由 CLI 或调用方导出 JSON，不视为业务持久化。

## 2. 模块边界

本模块负责：

1. 持久化 Request。
2. 记录 Request 状态历史。
3. 记录用户修改、接受、取消等操作历史。
4. 记录 AB 调用结果。
5. 保存 AB 降级配置生成结果。
6. 提供 Request 查询和恢复能力。

本模块不负责：

1. Request 字段结构定义。
2. 用户交互。
3. AB 调用。
4. RSS 拉取和解析。
5. 日志系统。

## 3. 存储范围

后续阶段至少需要存储：

1. Request。
2. Request 状态。
3. 用户修改历史。
4. 用户偏好配置引用或快照。
5. 番剧简称配置引用或快照。
6. 字幕组简称配置引用或快照。
7. AB 调用结果。
8. AB 降级配置生成结果。
9. 用户配置文件。

日志不作为普通业务数据混入 Request 存储，应由 M12 独立记录。

## 4. 存储方案

后续持久化阶段优先使用本地 JSON 文件，暂不接入数据库系统。

可选方案：

1. 本地 JSON 文件。
2. SQLite。
3. PostgreSQL。
4. 其他轻量数据库。

数据库方案作为后续扩展，不进入第一阶段。

## 5. 运行数据目录

运行数据目录用于保存 Request、状态历史、AB 调用结果和降级配置。

具体目录结构待技术设计确认。
