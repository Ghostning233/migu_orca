# Auto Bangumi 3.1.18 下载路径配置契约调查

归档结论（2026-09-23）：本轮设置页不提供 Auto Bangumi 下载路径修改功能，改为准确命名现有的「MiGuOrca 本地数据」分组。本调查只用于说明两种路径并非同一概念；不是现行开发规格，也不构成后续实施授权。

> 调查日期：2026-09-23。范围：Auto Bangumi 官方仓库 `3.1.18` tag（指向 commit `81b3a4aacd41e93032d809b27a69ebdd431a4ed0`）、该 tag 内官方文档，以及当前 MiGuOrca 代码与契约。仅做静态只读调查；未访问真实 Auto Bangumi 实例，未执行配置写入。
>
> 版本锚点：[官方 Git tag ref](https://api.github.com/repos/EstrellaXD/Auto_Bangumi/git/ref/tags/3.1.18)。以下上游链接均固定在此 commit，避免把新版契约误当 3.1.18。

## 结论

**确定：**用户所说的下载器设置确实存在。3.1.18 的配置 JSON 字段是 `downloader.path`，UI 称为 **Download path**，默认值 `/downloads/Bangumi`；不是 `download_path` 这个 JSON 键，也不是 MiGuOrca 的 `storage_dir`。[官方配置模型](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/models/config.py#L13-L21)、[官方下载器文档](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/docs/config/downloader.md#L43-L56)、[官方 Web UI 字段](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/webui/src/components/setting/config-download.vue#L49-L57)。MiGuOrca 的 `storage_dir` 则只解析服务端本地业务存储根下的相对 profile，语义不同；见 [`services.py`](../../src/apps/migu_orca_web/services.py#L66-L101)。

**确定：**3.1.18 有认证后的 `GET /api/v1/config/get` 和 `PATCH /api/v1/config/update`，但没有在核对的配置路由中发现只读/修改 `downloader.path` 的独立端点。[官方路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L10-L37)、[路由前缀](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/__init__.py#L13-L21)、[应用 `/api` 前缀](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/main.py#L29-L35)。

**确定：**MiGuOrca 当前没有这项 AB 配置读取/修改能力。现有设置端点管理的是 MiGuOrca 保存的 **AB 连接**（地址、认证秘密、安全摘要），以及连接探测，不是 AB 自身的 `downloader` 配置；见 [`routes_settings.py`](../../src/apps/migu_orca_web/routes_settings.py#L57-L128)、[`schemas.py`](../../src/apps/migu_orca_web/schemas.py#L308-L345) 与 [端点清单](../api/endpoint_inventory.md#L76-L78)。现有 3.1.18 管理 adapter 的读取对象是状态、番剧和 RSS，并在精确版本不符时拒绝；见 [`ab_management_client.py`](../../src/ab_engine/controllers/ab_management_client.py#L36-L59)。其 capability 模型没有下载路径能力项；见 [`management.py`](../../src/ab_engine/models/management.py#L16-L35)。

## 3.1.18 API 与写入语义

| 问题 | 判定 | 证据与边界 |
| --- | --- | --- |
| 读取 | **确定** | `GET /api/v1/config/get` 返回整个 `Config`，其中含 `downloader.path`，也含下载器和其他分区的秘密。不能把上游完整响应直接透传给 MiGuOrca 浏览器。[配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L14-L16)、[完整模型](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/models/config.py#L13-L34)、[本仓库秘密边界](../MiGuOrca_stage39_deployment_settings_PRD.md#L89-L95)。 |
| 写入 | **确定** | `PATCH /api/v1/config/update` 接收 JSON 的 `Config`，执行 `settings.save(config_dict=config.dict())`，随后 `settings.load()`；成功返回 HTTP 200 和 `msg_en/msg_zh`，异常返回 406。没有路径专用 PATCH。[配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L19-L37)、[官方 Web UI 调用](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/webui/src/api/config.ts#L13-L23)。 |
| 局部更新还是完整替换 | **确定** | 尽管 HTTP 动词是 PATCH，服务端保存的是整个 `Config.dict()`，`Settings.save` 以 `"w"` 打开整份配置文件并序列化完整对象；`Config` 的各分区有默认值，故只发送 `{"downloader":{"path":...}}` 不构成安全的局部合并，缺失字段可能被默认值取代。[路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L19-L25)、[模型默认值](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/models/config.py#L112-L123)、[磁盘写入](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/conf/config.py#L45-L49)。 |
| 认证 | **确定** | 两个配置路由均依赖 `get_current_user`：从名为 `token` 的 Cookie 验证 JWT 且用户名必须在进程内 `active_user`。登录为 `POST /api/v1/auth/login`，提交 OAuth2 password form 的用户名/密码，成功时设置 `token` Cookie。登录响应也含 access token，但配置路由读取 Cookie，不按 Bearer 头认证。[配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L14-L22)、[认证依赖](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/security/api.py#L14-L25)、[登录](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/auth.py#L22-L31)。本仓库已有同版本登录/Cookie adapter，但只用于现有能力；见 [`ab_management_client.py`](../../src/ab_engine/controllers/ab_management_client.py#L184-L206)。 |
| 并发保护、单字段写入 | **未知/未见** | 所核对的配置路由没有 revision、ETag、compare-and-swap 或字段级 patch 参数；整份配置读改写可能覆盖并发修改。不能把 MiGuOrca 保存连接的 `configuration_revision` 当作 AB 配置版本；它只约束 MiGuOrca 自己的连接文件。[官方配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L14-L37)、[本仓库连接版本语义](../MiGuOrca_stage39_deployment_settings_PRD.md#L77-L85)。 |

## 路径含义与应用时机

- **确定：**官方文档要求 `downloader.path` 与下载器视角下的路径参数一致。Docker 示例中 qB 的 `/downloads` 映射到宿主机目录，AB 应填 `/downloads/Bangumi`；Linux/macOS、Windows 示例同样按下载器的目录写。官方说明 AB 使用此值生成番剧文件路径，AB 自身不直接管理该路径下的文件。因此它不是 MiGuOrca 服务进程的本地存储目录，也不能直接推定是 AB 容器内必须挂载的目录。[官方下载器文档](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/docs/config/downloader.md#L32-L41)、[官方组合部署示例](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/docs/resource/docker-compose/qBittorrent+AutoBangumi/docker-compose.yml#L3-L24)、[生成 save_path 的源码](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/downloader/path.py#L55-L61)。
- **确定：**生成的新番剧路径是 `downloader.path / 番剧文件夹 / Season N`，并可作为 qB RSS 规则 `savePath` 或添加 torrent 时的 `save_path`。若配置路径为空，下载器初始化会读取 qB 默认 `save_path` 并在内存中附加 `Bangumi`；没有证据表明这个回填会立即保存回 AB 配置 JSON。[路径生成](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/downloader/path.py#L55-L61)、[下载器逻辑](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/downloader/download_client.py#L56-L90)、[添加 torrent](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/downloader/download_client.py#L117-L143)。
- **确定：**配置 PATCH 会写磁盘并重载全局 `settings`，但路由本身没有调用程序 restart。3.1.18 官方 Web UI 在 PATCH 成功后另行调用 `/api/v1/restart`；该 restart 会 stop/start 内部工作线程，`start()` 再次加载配置。因此“PATCH 成功”与“官方 UI 完成应用流程”是两个步骤。[配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L19-L27)、[Web UI store](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/webui/src/store/config.ts#L11-L20)、[restart 路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/program.py#L30-L36)、[Program.restart/start](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/core/program.py#L61-L72)。
- **推断：**新路径影响后续由 AB 生成的规则/任务路径；没有从上述配置路由看到既有番剧、已创建的 qB 规则、下载任务或媒体迁移逻辑。不能承诺修改配置会搬迁已有下载或追溯修改原规则。[配置路由](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/api/config.py#L19-L37)、[规则生成](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/backend/src/module/downloader/download_client.py#L72-L90)。
- **未知：**在未运行真实 3.1.18 实例的前提下，无法证明只 PATCH 而不 restart 时所有正在运行的工作循环何时、是否采用新路径，也无法证明重启操作在具体部署中一定成功。官方 UI 的实际流程提示实现时需把写配置和应用结果分别处理。[Web UI store](https://github.com/EstrellaXD/Auto_Bangumi/blob/81b3a4aacd41e93032d809b27a69ebdd431a4ed0/webui/src/store/config.ts#L11-L20)。

## 历史方案假设（不在现行需求内）
